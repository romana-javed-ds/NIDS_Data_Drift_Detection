# Network Intrusion Detection and Data Drift Detection

## Research Overview

This research project focuses on evaluating data drift signals in Machine Learning-based Network Intrusion Detection Systems (NIDS).

The study investigates how changes in network traffic distributions may relate to machine learning model performance over time.

## Research Dataset

**CIC-IDS2017**

A network intrusion detection dataset used to study network traffic and intrusion detection.

## Research Objectives

- Analyze network traffic data.
- Perform dataset inspection and auditing.
- Investigate feature distribution changes.
- Explore statistical drift detection methods.
- Study model performance across chronological data windows.
- Examine the relationship between drift signals and performance degradation.

## Methodology

The research investigates:

- Kolmogorov–Smirnov (KS) Test
- Population Stability Index (PSI)
- Jensen–Shannon Divergence (JSD)
- Feature importance analysis
- Temporal evaluation of machine learning models
